## 📌 Project Overview

This project is a **Smart City Traffic & Retail Analytics case study** developed using **Python and NumPy**.

The case study works with different datasets related to:

- 🚦 Traffic
- 🛍️ Retail Sales
- 🌦️ Weather

The objective is to practice NumPy-based data analysis techniques and extract meaningful patterns and insights from structured datasets.

---

## 🎯 Objectives

The main objectives of this case study are:

- Understand NumPy arrays and their structures
- Perform array reshaping and manipulation
- Apply slicing and indexing techniques
- Perform aggregation and statistical calculations
- Work with Boolean masking
- Apply conditional operations
- Understand NumPy broadcasting
- Perform sorting and indexing operations
- Generate random samples
- Analyze trends and patterns in data
